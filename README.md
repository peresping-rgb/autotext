# Autotext ✍️

A free, AI-powered word processor designed for writing in Swedish — perfect for students and anyone who wants help expressing themselves in writing.

## Features

- ✨ **AI writing assistance** — improve your text, get feedback, or let AI write a first draft (requires a free [Groq API key](https://console.groq.com))
- 📝 **Rich text editor** — headings, lists, bold, italic and more
- 🌍 **24 languages** — the interface works in Swedish, English, Arabic, Somali, and many more
- 🎯 **Focus mode** — distraction-free writing
- 📊 **Presentation mode** — turn your document into slides
- ⬇️ **Export** — download as Word (.docx) or PDF
- 🌙 **Dark mode**
- 💾 **Auto-save** with version history
- 📱 **Works on mobile**
- 🔒 **No account needed** — everything stays in your browser

## How to use

Open the app and start writing. To activate AI features, click the 🔑 key icon and enter your Groq API key (free at [console.groq.com](https://console.groq.com)).
